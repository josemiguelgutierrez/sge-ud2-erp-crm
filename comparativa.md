# Licencias y modelos
## Software Libre

El software libre es un tipo de programa cuyo código se puede ver, modificar y compartir. Aparte de ser gratis, da libertad para usarlo como quieras y adaptarlo si lo necesitas.


Normalmente no se paga licencia, pero eso no significa que no tenga costes, puede haber gastos de instalación, soporte o mantenimiento. La idea principal es que no dependes de una empresa concreta, sino de una comunidad que lo mantiene y lo mejora.

## Código abierto

El código abierto es parecido al software libre, pero sues más práctico. También puedes ver y modificar el código, pero se centra más en cómo se desarrolla el programa entre muchas personas que colaboran.


Suele ser más económico y se actualiza rápido porque hay mucha gente aportando. La diferencia es que el software libre se centra más en la libertad del usuario, mientras que el código abierto se centra en la forma de trabajar y mejorar el software.

## Software propietario

El software propietario es el programa de una empresa donde el código es privado y para usarlo tienes que pagar una licencia.


Este tipo de software suele tener una interfaz más profesional, mejor rendimiento y soporte técnico oficial. Lo malo es que suele ser más caro.

## Por qué libre no significa gratuito

Libre no es lo mismo que gratis, porque libre significa que tienes libertad para usar y modificar el programa, pero aun así puede haber costes como: instalación, personalización, soporte...

## Community vs Enterprise

Las versiones Community son las gratuitas y traen lo básico para poder usar el programa sin pagar licencias. Suelen depender de la comunidad para resolver dudas y mejorar el software, así que avanzan rápido pero sin garantías ni soporte profesional. 


Y las versiones Enterprise son de pago y están pensadas para empresas que necesitan más funciones, más estabilidad y un soporte técnico oficial que responda cuando hay problemas. 


En resumen, Community es la opción sencilla y sin coste, y Enterprise es la opción completa y profesional, pero pagando.

## ERP libre: Odoo Community

**Licencia:** Odoo Community utiliza la licencia GNU LGPLv3. Enlace: https://www.odoo.com/documentation/20.0/legal/licenses.html

**Versión vigente:** La versión vigente es Odoo 20.0. Enlace: https://www.odoo.com/documentation/20.0/administration/on_premise/source.html

**Lenguaje delservidor:** El servidor está desarrollado principalmente en Python. Para Odoo 20 se requiere Python 3.12 o posterior. Enlace: https://www.odoo.com/documentation/20.0/administration/on_premise/source.html

**SGBD compatibles:** Odoo utiliza PostgreSQL como sistema gestor de bases de datos. Para la versión vigente se requiere PostgreSQL 16 o superior. Enlace: https://www.odoo.com/documentation/20.0/administration/on_premise/source.html

**Modalidad:** Puede utilizarse mediante instalación local/on-premise o mediante servicios en la nube de Odoo. La documentación oficial contempla tanto instalaciones on-premise como Odoo Online y Odoo.sh. Enlace: https://www.odoo.com/documentation/20.0/administration.html

**Módulos principales:** Sus módulos principales son CRM, Ventas, Contabilidad, Facturación, Inventario, Fabricación, Punto de Venta, Proyectos, Recursos Humanos, Marketing, Comercio electrónico y Sitio web. Enlace: https://www.odoo.com/documentation/20.0/applications/general/apps_modules.html

**Requisitos principales:** Python 3.12 o superior, PostgreeSQL 16 o superior, Dependencias de Python indicadas en requirements.txt, Git y herramientas de compilación de C++ de Visual Studio para dependencias. Enlace: https://www.odoo.com/documentation/20.0/administration/on_premise/source.html

# Decisiones en la matriz

Tras evaluar las tres opciones (ERPNext+SuiteCRM, Odoo Community+SuiteCRM y Dynamics+Zoho) según a lo que le puede venir mejor a mi empresa, he asignado puntuaciones del 1 al 5 y aplicado los pesos. Los totales ponderados quedan así: ERPNext+SuiteCRM obtiene 3,65, Odoo Community+SuiteCRM 4,10 y Microsoft Dynamics+Zoho 4,35.

Aunque Microsoft Dynamics sea la que mejor puntúa técnicamente, al ser cara y que depende del proveedor, yo creo que no sería tan adecuado para mi empresa. Por eso ccreo que la opción de Odoo Community + SuiteCRM es la mejor opción ya que permite integrar tienda física y web, mejora el control del stock y facilita crear un portal de pedidos sin licencias de pago, además de ser más fácil de usar para los seis empleados.

Aun así, lógicamente hay riesgos como que algunas funciones requieren configuración adicional, hay cierta dependencia de desarrolladores para personalizar módulos y para una futura migración a Odoo Enterprise podría significar que habría que pagar. Pero aún así, es la que yo veo mejor con lo que necesita y el presupuesto de mi empresa.
